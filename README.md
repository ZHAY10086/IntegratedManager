# IntegratedManager

## Description

IntegratedManager is an addon to the
[IntegratedDynamics](https://www.curseforge.com/minecraft/mc-mods/integrated-dynamics)
set of mods for Minecraft.

It adds the "Manager Tablet" item, which tries to visualize the state of the clicked network.
Instead of having to check each part and variable individually, you can now simply click a part
and see how data flows through your network.
